The Hunters — Predator/Prey Simulation
Project Overview

The Hunters is a 2D simulation built in MonoGame that models a simple ecosystem with foxes (predators) and rabbits (prey). Rabbits move around the environment, flee from foxes when flee mode is enabled, and are removed when caught. Foxes actively hunt nearby rabbits and manage hunger and reproduction. The simulation also includes grass zones that influence rabbit movement.

The project demonstrates animation hierarchies, interactive GUI systems, and basic data persistence.

How to Run
Open the project in Rider
Build and run the game
Use the main menu to adjust settings
Press ENTER to start the simulation

Controls
Main Menu
Arrow Keys — Adjust fox count, rabbit count, and settings
S — Toggle sound on/off
ENTER — Start simulation

In-Game
B — Toggle rabbit flee mode
P — Pause/resume simulation
M — Mute/unmute sound
R — Reset simulation
+ / - — Increase/decrease speed
ESC — Return to main menu

Features
Autonomous fox and rabbit behavior
Real-time HUD displaying population stats
Interactive main menu configuration screen
Toggleable flee behavior
Basic sound system integration (mute/unmute support)
Animation hierarchy for both animals
